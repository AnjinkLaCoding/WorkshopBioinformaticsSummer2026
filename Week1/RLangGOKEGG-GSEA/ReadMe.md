# Differential Expression and Functional Enrichment Analysis of Rheumatoid Arthritis (Early vs. Established) and Healthy Synovial Tissue Using R Language
## Description
##### This project investigates transcriptomic changes in synovial tissue across rheumatoid arthritis (RA) progression using publicly available RNA-seq data (GEO accession GSE89408). Raw gene expression counts from synovial biopsies of healthy controls (Normal), early-stage RA, and established RA patients were analyzed using DESeq2 to identify differentially expressed genes (DEGs) between disease stages. Pairwise comparisons (Early RA vs. Normal, Established RA vs. Normal, and Established vs. Early RA) were performed to characterize both disease-associated and progression-associated gene expression signatures. Downstream functional enrichment analyses — including Gene Ontology (GO), KEGG pathway enrichment, and Gene Set Enrichment Analysis (GSEA) — will be applied to the resulting DEG lists to identify biological processes and pathways implicated in RA onset and progression.
